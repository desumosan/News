# 3分でわかる日本経済

日本経済ニュースを「3分で理解する」ための静的Webサイトのプロトタイプです。

## 現在
- スマホ対応
- 今日の重要ニュース3本
- 日銀・為替・株式のクイック指標
- 「なぜ重要？」「生活への影響？」の説明
- 用語解説
- 出典・免責表示

## 自動化する次の構成
1. ニュースRSS/API等から候補を収集
2. ChatGPT: 重要度・重複・要点を整理
3. Claude: 読みやすい日本語記事へ編集
4. Jev: 必要なら独自の経済スコア/分類を担当
5. JSONを生成
6. 静的HTMLを自動更新
7. GitHub Pages等へデプロイ

## データ設計例
```json
{
  "date": "2026-09-20",
  "articles": [
    {
      "title": "...",
      "what": "...",
      "why": "...",
      "impact": "...",
      "sources": ["..."]
    }
  ]
}
```

このプロトタイプはニュース本文を無断転載せず、要約と出典表示を前提にしています。
